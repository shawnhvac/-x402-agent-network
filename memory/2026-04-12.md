## Technical Details

### Wallet Detection Flow
1. App loads → MultiWalletManager.discoverInstalledWallets()
2. Queries PackageManager for: app.phantom, com.solflare.mobile, com.jupiter.app
3. Returns list of installed wallets
4. UI shows only installed wallets in modal
5. User selects wallet → connectWallet(WalletType)
6. State saved to SharedPreferences

### Deep Link Signing
- App builds transaction (base64)
- Sends to wallet via deep link with returnUrl
- Wallet app handles signing (user approval required)
- Returns signed transaction to agentpay:// scheme
- App extracts signature and submits to Solana network
