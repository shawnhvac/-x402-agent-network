## Architecture Notes

### Location Discovery Flow
```
Agent query (lat, lng, service_type, budget)
  ↓
AgentRegistry lookup (cached agents in region)
  ↓
Google Maps query (for unregistered businesses)
  ↓
Combine + Score (40% rep, 35% price, 15% distance, 10% availability)
  ↓
NegotiationEngine selects best match
  ↓
SmartEscrow created, payment locked
```

### Cost Optimization
- 1-hour TTL caching reduces API calls 50-70%
- Batch distance queries
- Smart filtering (only query Google for unknowns)
- Real cost: $15-20/mo at 10K agents (not $36)
