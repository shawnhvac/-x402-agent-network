### Architecture — 100% Non-Custodial

1. User connects wallet → bot stores PUBLIC key only
2. User initiates snipe → bot creates unsigned transaction
3. Bot provides two options:
   - Jupiter link (1-tap on mobile, preferred)
   - Base64 (fallback for manual signing)
4. User reviews & signs in their wallet app (Phantom, Solflare, Magic Eden)
5. Bot receives signed transaction from user
6. Bot broadcasts to Raydium network
7. User keeps ALL funds, bot takes 3% fee from output only
8. **No private keys ever stored, sent, or accessed by bot**
