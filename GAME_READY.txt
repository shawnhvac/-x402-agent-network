🚀 HOW TO DEPLOY (EASY - 5 MINUTES)
================================================================================

OPTION A: Vercel (EASIEST - Recommended)
────────────────────────────────────────
1. Sign up at vercel.com (free)
2. Run:
   npm install -g vercel
   cd /root/.openclaw/workspace/muskox-game-server
   vercel --prod

3. Wait 2 minutes
4. Game is LIVE at: https://game.elonmuskoxnft.com/game.html

OPTION B: Your VPS
──────────────────
1. Copy files to VPS:
   scp -r /root/.openclaw/workspace/muskox-game-server user@your-vps:/var/www/

2. SSH into VPS and run:
   cd /var/www/muskox-game-server
   npm install
   node server.js

3. Point DNS: game.elonmuskoxnft.com → your VPS IP

4. Get SSL (free):
   certbot certonly --standalone -d game.elonmuskoxnft.com

5. Set up Nginx (see GAME_DEPLOYMENT.md)

6. Game is LIVE!

OPTION C: Use Existing Web Hosting
───────────────────────────────────
1. Upload game.html to: /public_html/game.elonmuskoxnft.com/game.html
2. Make sure HTTPS is enabled
3. Game is LIVE!
