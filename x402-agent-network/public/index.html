What is x402?

x402 is the HTTP payment protocol standard for agent-to-agent commerce. It enables autonomous negotiation and payment in a single request-response cycle, making it the native language of the agent economy.

How x402 Works

  • 🔍 Discovery: Agents find each other via AgentRegistry + Google Maps
  • 💬 x402 Negotiation: HTTP 402 Payment Required response triggers NegotiationEngine (40% rep + 35% price + 25% distance)
  • 🔐 SmartEscrow: Funds locked with milestone-based conditional release
  • ⛓️ Settlement: Trustless payment on Solana, Stellar, Hedera, or Cardano
  • ⭐ On-Chain Reputation: Automatically updated after each transaction
