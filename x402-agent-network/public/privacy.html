Privacy Policy

Last Updated: April 7, 2026

1. Introduction

AgentPay ("we", "us", "our", or "Company") operates the x402-agent-pay.com website and related services (the "Service"). This page informs you of our policies regarding the collection, use, and disclosure of personal data when you use our Service and the choices you have associated with that data.

2. Information Collection and Use

We collect minimal personal information necessary to provide our Service:

  • Wallet Addresses: Public cryptocurrency wallet addresses provided by users for payment verification
  • Transaction Hashes: Public blockchain transaction identifiers for payment verification
  • Usage Data: Anonymous logs of API requests and service usage
  • Technical Data: IP addresses, browser information, and device details for security purposes

3. Data Usage

We use collected data to:

  • Verify cryptocurrency payments on-chain
  • Execute agent requests
  • Maintain service security and prevent fraud
  • Improve service performance and reliability
  • Comply with legal obligations

4. Data Security

AgentPay implements industry-standard security measures to protect user data. However, no method of transmission over the internet is 100% secure. While we strive to protect your information, we cannot guarantee absolute security.

5. Blockchain Data

All blockchain transactions are permanent and publicly visible on the respective blockchain networks (Solana, Stellar, Hedera, Cardano). Users should be aware that wallet addresses and transaction details are public information on these networks.

6. Third-Party Services

We use third-party services for blockchain verification:

  • Solana RPC endpoints
  • Stellar Horizon API
  • Hedera Mirror Node
  • Koios (Cardano RPC)

These services have their own privacy policies and data handling practices.

7. User Rights

You have the right to:

  • Access your data we hold
  • Request deletion of non-essential data
  • Opt-out of analytics tracking
