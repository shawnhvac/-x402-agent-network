## 🚨 INSTALLATION TROUBLESHOOTING

**Issue: "App not installed"**
- Go to Settings > Security > Unknown Sources (enable)
- Try again

**Issue: "Can't connect to wallet"**
- Ensure Phantom/Magic Eden app is installed
- Check internet connection
- Update to latest AgentPay version

**Issue: "Old version showing"**
- Uninstall previous version: `adb uninstall com.agentpay`
- Install new: `adb install agentpay-2.0.0.apk`
- Clear cache: Settings > Apps > AgentPay > Storage > Clear Cache
