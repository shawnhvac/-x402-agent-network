## Grok Imagine Settings & Tips

### Recommended Settings for All Videos

**Resolution:** 1080p (Full HD) or 1440p (if available)  
**Aspect Ratio:** 16:9 (YouTube/desktop) or 9:16 (TikTok/Reels)  
**Duration:** Let Grok auto-generate (usually 30-60s)  
**Style:** "Cinematic," "Futuristic," "Professional"  
**Color Tone:** "Neon purple and cyan"  

### Grok Imagine Pro Tips

1. **Use Specific Numbers:** Instead of "fast," use "$2.80/unit," "75% efficiency," "$1,650 price"
   - Grok AI responds better to concrete details

2. **Visual Hierarchy:** Always mention what should be "glowing," "highlighted," "crowned"
   - Helps AI emphasize the winning option

3. **Lighting Directives:** "Neon," "glow," "holographic" → consistent futuristic aesthetic
   - Repeat purple/cyan color values throughout

4. **Action Verbs:** "appearing," "lighting up," "animated," "floating"
   - More cinematic than static descriptions

5. **Camera Direction:** Mention "drone," "close-up," "wide shot," "zoom"
   - Helps Grok compose dynamic shots

6. **Brand Elements:** Always include "futuristic," "sleek," "professional"
   - Maintains consistent AgentPay™ aesthetic

## Post-Production in Grok Imagine

### If Grok Generates Without Audio:
1. Export video from Grok
2. Use separate voiceover tool (Eleven Labs, Google TTS, etc.)
3. Sync voiceover to video timeline in editing software (CapCut, DaVinci Resolve)
4. Add background music (royalty-free, ~120 bpm synth)

### Color Grading:
- Grok should handle this, but if needed:
  - Enhance purple/cyan tones in post
  - Increase contrast for neon effects
  - Add slight glow/bloom to highlights

### Text Overlays (Optional):
- Add AgentPay™ logo at beginning
- CTA text at end: "x402-agent-pay.com"
- Video title on intro frame
