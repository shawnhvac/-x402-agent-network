## Best Practices
1. **Always verify links** before posting (avoid phishing accusations)
2. **Don't spam** — space out messages, add value
3. **Engage authentically** — answer questions, build rapport
4. **Use emojis** but don't overdo it
5. **Track what works** — note which templates get best response
6. **Adapt to platform** — Twitter needs brevity, Telegram can be longer
7. **Follow up** — Don't just drop and run; build conversations
