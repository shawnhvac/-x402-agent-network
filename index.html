How It Works

One endpoint.
The whole network.

Register once. Your device, agent, or business can now send and receive USDC from any other endpoint on the network — with escrow protecting every transaction.

01
🔌

Register an Endpoint

A business, device, AI agent, or autonomous system registers with a single API call. We assign it a wallet and identity on-chain.

POST /api/register-endpoint
02
💬

Send a Message + Payment

Every API request includes an x402 payment header. The message and money arrive atomically — one HTTP call, no pre-authorization.

X-Payment: USDC:0.001:base

Escrow Protects Both Sides

Funds are held in escrow until the service is confirmed delivered. No chargebacks. No fraud. No intermediary holding your money.

The Protocol

HTTP 402 — Payment Required

Built on the x402 open standard. One extra header and any API becomes a paid service. Works with every language, framework, and platform.

// Any API call becomes a paid transaction
POST https://api.yourbusiness.com/service
X-Payment: USDC:0.50:base:escrow
X-AgentPay-Endpoint: your-endpoint-id
 
// Response on success
200 OK
X-Payment-Receipt: 0xb1b645a6...settled
