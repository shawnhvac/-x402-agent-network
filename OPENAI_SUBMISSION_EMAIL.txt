API ENDPOINTS
─────────────

POST /api/v1/search ($0.001 per call)
  - Search available services by category and location
  - Input: { category, location, date?, filters? }
  - Output: Array of matching services with ratings and availability

POST /api/v1/book ($0.002 per call)
  - Book a service appointment
  - Input: { service_id, date, time, notes? }
  - Output: { booking_id, status, confirmation_url }

POST /api/v1/pay ($0.001 per call)
  - Complete payment for a booked service
  - Input: { booking_id, amount, payment_method }
  - Output: { transaction_id, status, receipt_url }
